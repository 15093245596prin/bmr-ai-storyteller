# 黯月初升 · AI说书人 MVP

一个可在手机浏览器运行的《血染钟楼》辅助/自动说书人原型。腾讯会议负责公聊，本项目负责房间、秘密身份、夜间行动和规则结算。

## 运行
需要 Node.js 20+：

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。同一局域网的朋友可用你电脑的局域网 IP + `:3000` 访问；公网联机需要部署到服务器/云平台。

## 已实现
- 创建/加入房间、秘密身份、昼夜状态、Socket.IO 实时同步
- 《黯月初升》图中角色的数据定义
- 夜间行动队列
- 第一批确定性结算：旅店老板保护、弄臣首次免死、水手免死、教授、刺客、普卡、沙巴洛斯、珀/僵怖的基础死亡流程
- 规则引擎与 UI 分离

## 重要：当前仍是 MVP，不可声称完整规则等价
尚需实现：完整官方夜间顺序、双目标/三目标 UI、醉酒/中毒的信息生成、茶艺师邻座、莽夫转阵营、驱魔人、赌徒、祖母、侍女、教父、魔鬼代言人、吟游诗人、月之子、主谋、僵怖“被视为死亡”、沙巴洛斯复活裁量、提名/投票/处决、完整胜负条件，以及所有交互冲突测试。

下一阶段应优先补齐 `engine.js` 的事件系统和自动测试，再接 AI 裁量层。AI 只能从规则引擎给出的合法选项中选择，不能直接改状态。

## v0.2 公网部署（Render）

此版本已适配公网 Node Web Service：
- 使用 Render 提供的 `PORT` 环境变量；
- 监听 `0.0.0.0`，允许平台公网代理访问；
- 提供 `/health` 健康检查；
- Socket.IO 已配置心跳参数；
- 根目录提供 `render.yaml`。

部署流程：把本目录上传到 GitHub，然后在 Render 创建 Web Service/Blueprint，连接该仓库即可。
